# Health Bridge

A healthcare website for finding doctors and hospitals, booking appointments, and getting vaccine reminders.

## Features
- Doctor and hospital suggestions
- Appointment booking
- Vaccine reminders
- Emergency ambulance request

## How to run
1. Clone the repo
2. Open `index.html` in your browser
